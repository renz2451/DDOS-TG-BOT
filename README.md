# 🔥 Attack Bot - Firebase Edition

A Telegram bot for stress testing and attack simulations.

## 🚀 Features

- 🎯 **Attack Simulation** - Launch stress tests on IP:Port
- 🔑 **Key System** - Generate and redeem access keys
- 📊 **Statistics** - Track attack history and success rates
- 📢 **Channel Verification** - Require channel join
- 👑 **Admin Panel** - Full management dashboard
- ⚡ **Real-time Updates** - Live attack progress

## 📦 Installation

### Prerequisites
- Python 3.11+
- Firebase Realtime Database
- Telegram Bot Token
